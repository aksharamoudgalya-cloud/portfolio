Investigate, ideate, validate

Every project touches all three, formally or informally. The case studies mark which phase each piece of work belongs to.

  1. Investigate

    Find out what is true

    Uncover the bias in the brief and narrow the need before anyone commits to a solution.

    Stakeholder and user interviews, focus groups, analytics, landscape reviews

  2. Ideate

    Work toward a solution

    Iterate in the open with the team, from rough structure to flows that hold together.

    Card sorting, user flows, wireframes, prototypes

  3. Validate

    Test before it ships

    Put assumptions in front of real users and real data, and let the evidence settle the argument.

    Tree testing, usability testing, A/B testing
